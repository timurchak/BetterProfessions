# BetterProfessions

Небольшой аддон для World of Warcraft Retail, который делает две части стандартного интерфейса профессий информативнее, не заменяя его целиком.

## Возможности

- В списке заказов сразу показывает чистую комиссию после удержания Консорциума.
- Показывает предметы и валюты из награды NPC-заказа без открытия заказа.
- Показывает обязательные реагенты, которые должен предоставить персонаж, их количество и наличие в сумках/банке.
- Рассчитывает ожидаемый профит по ценам Auctionator, TradeSkillMaster или Oribos Exchange и показывает полный разбор в подсказке.
- Показывает требуемую концентрацию, если текущего навыка недостаточно для минимального качества заказа.
- При выборе рецепта открывает отдельную компактную панель со специализациями, которые повышают навык именно для этого рецепта.
- Для каждого связанного узла показывает текущий ранг, максимум и текущий/максимальный бонус навыка; полное описание доступно в подсказке.
- Работает без обязательной зависимости от CraftSim, ProfessionShoppingList или аукционных аддонов.

Данные соответствий рецептов и специализаций сжаты в `Data/RecipeSpecializations.lua`. Названия, иконки, описания, текущие ранги и пороги талантов аддон получает напрямую через WoW API.

## Команды

- `/bp` — краткая справка.
- `/bp orders` — включить или выключить улучшенный список заказов.
- `/bp specs` — включить или выключить панель специализаций.
- `/bp reset` — сбросить настройки.

После переключения модулей требуется `/reload`.

## Локальная разработка

Локальный путь к Retail хранится в игнорируемом Git файле `.deploy.local.ps1`:

```powershell
$BetterProfessionsWowRoot = "F:\G\World of Warcraft\_retail_"
```

Основные команды:

```powershell
./scripts/Validate.ps1
./scripts/Deploy.ps1
./scripts/Watch.ps1
./scripts/Package.ps1
```

`Deploy.ps1` валидирует исходники и выполняет чистое копирование только в `Interface/AddOns/BetterProfessions`. `Watch.ps1` повторяет deploy при изменении runtime-файлов. `Package.ps1` создаёт готовый ZIP в `dist`.

## Обновление данных специализаций

Генератор принимает путь к установленному CraftSim и извлекает только минимальные числовые соответствия рецептов узлам, добавляющим навык:

```powershell
./scripts/Generate-SpecializationData.ps1 `
  -CraftSimRoot "F:\G\World of Warcraft\_retail_\Interface\AddOns\CraftSim"
```

CraftSim не нужен пользователю и не загружается аддоном. Генератор — инструмент сопровождения данных после крупных патчей профессий.

## CI и релизы

- `.github/workflows/ci.yml` проверяет Lua и собирает тестовый ZIP для `main`, `dev` и pull request.
- `.github/workflows/release.yml` запускает BigWigs packager для тегов `v*`, создаёт GitHub Release и готов к публикации на CurseForge после добавления project ID и секрета `CF_API_KEY`.
- Версия тега должна совпадать с `## Version` в `BetterProfessions.toc`.
